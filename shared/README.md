# shared

这里保存小程序与云函数共同遵守的请求、响应、错误码和领域枚举。共享契约必须先在实施规划冻结，再进入代码；不得把数据库凭据或服务端用户身份逻辑下放到客户端。

`catledger-api.json` 描述当前开发接口。客户端只发送公开动作和业务字段，用户身份由云函数可信上下文取得，`bootstrap` 只向当前用户返回其唯一的10位数字字符串 `uid`（页面称 ID，首位非0），其他字段按动作白名单返回；响应不包含 OpenID 或身份摘要，普通日志不记录 uid。客户端传入 uid 仍被拒绝，展示 ID 不改变业务鉴权。开发阶段直接更新这一份契约，不维护并行接口。

UID切换见 MINI-1904F 与 `migrations/0011_short_user_ids.sql`：内部主键、所有业务归属、页面显示与复制统一为同一ID，没有额外公开编号。迁移前的旧UUID响应仅用于过渡兼容；其他实体ID和requestId格式不变。
