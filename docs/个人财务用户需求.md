# 猫账个人财务用户需求

## 1. 产品定位

猫账是一款面向中国个人用户的微信小程序记账工具。产品不是要求用户每天逐笔维护账本，而是让用户定期上传支付宝、微信支付等账单，系统完成解析、去重、整理和批量入账；用户只处理真正有歧义的项目。

小程序面向公众提供服务并保留多用户隔离。原 Web 版进入维护归档，不再决定新产品的信息架构。

## 2. 核心用户流程

1. 用户通过微信身份进入自己的账本。
2. 首次使用时获得默认分类，并创建或确认常用资金账户。
3. 用户可以手动记一笔，也可以一次选择多份账单上传。
4. 系统逐文件解析、识别账户和来源身份，明确项目自动整理，有歧义项目集中询问。
5. 用户确认整批结果后一次入账；重复提交不会生成重复交易。
6. 首页和交易页只统计正式入账数据，并可按月份、分类和账户查看。

## 3. 首发必须具备

- 微信身份登录与多用户数据隔离；
- 默认分类、账户管理和手动记账；
- 交易列表、月份筛选、搜索与基础统计；
- 支付宝、微信支付账单的多文件选择、上传、解析、整理、去重和整批入账；
- 原始证据下钻、人工纠错、失败文件隔离和安全重试；
- 数据导出、账户注销与隐私说明。

## 4. 后续能力

- 银行账单模板扩展；
- 贷款、分期和还款计划；
- 图片或剪贴板辅助记账；
- 更丰富的统计和年度回顾。

后续能力不得拖慢首发核心闭环。

## 5. 明确不做

- 桌面客户端、PWA 和移动 Web；
- 云托管、常驻服务器和与小程序并行的第二套正式账本；
- 洞察探索、交易模板、定时交易、标签体系、地图和机构管理；
- 为追求“万能导入”而承诺所有银行 PDF 都能解析；
- 未具备合规主体和官方支付能力时的付费、会员或激活码绕行方案。

## 6. 体验原则

- 简体中文优先，界面只呈现个人记账所需概念；
- 结果优先，技术字段和原始证据按需下钻；
- 批量导入是主能力，不隐藏在低频设置中；
- 不确定时宁可询问，不静默猜测或合并；
- 原始账单上传后应明确说明用途、保存时间和删除规则。
