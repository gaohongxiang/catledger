### 不依赖附件的读取方式

Astra 可直接使用已连接的 GitHub `fetch_blob`，参数为 `repository_full_name="gaohongxiang/catledger"` 和表内 `blob_sha`。也可用已经登录的 GitHub CLI GET 同一对象：

```bash
gh api repos/gaohongxiang/catledger/git/blobs/a04c04a30ad0f6d772e2bece9c3c685b64915158
```

以下自包含脚本读取全部五项，在系统临时目录创建新目录，解码并验证 Git blob SHA 后保存，仅供比对。无需任何额外脚本、清单文件或 ZIP；不会覆盖工程，不提交、不推送、不修改权限。需要 Python 3 和已登录的 gh，不要把 Token 提供给聊天。

```bash
python3 - <<'PY'
import base64
import hashlib
import json
import pathlib
import subprocess
import tempfile

repo = 'gaohongxiang/catledger'
items = {
    'cloudfunctions/catledger-import/src/finance-update-posting.js': 'a04c04a30ad0f6d772e2bece9c3c685b64915158',
    'miniprogram/pages/import-workbench/transaction-review.js': '479cf26e9f30a4c6edd5da5db0160575dd85405a',
    'miniprogram/pages/import-workbench/account-review.js': '297aa7a9e58106c9707d02e6aa15d07364dae710',
    'cloudfunctions/catledger-import/src/review/issue-store.js': '4ff47307eaf32e70767de086fbd3ff4b340ad612',
    'miniprogram/pages/import-workbench/review-edit.wxml': 'e190274f66efa258214d15ea37348df72d865e9b',
}
root = pathlib.Path(tempfile.mkdtemp(prefix='catledger-editor-candidates-'))
print('候选比对目录：', root)
for name, sha in items.items():
    response = subprocess.run(
        ['gh', 'api', f'repos/{repo}/git/blobs/{sha}'],
        check=True, capture_output=True, text=True, timeout=60,
    )
    blob = json.loads(response.stdout)
    if blob.get('encoding') != 'base64' or blob.get('sha') != sha:
        raise RuntimeError(f'对象格式或 SHA 不符：{name}')
    content = base64.b64decode(''.join(blob['content'].split()), validate=True)
    actual = hashlib.sha1(f'blob {len(content)}\0'.encode('ascii') + content).hexdigest()
    if actual != sha:
        raise RuntimeError(f'内容校验失败：{name}')
    target = root / name
    target.parent.mkdir(parents=True, exist_ok=True)
    with target.open('xb') as handle:
        handle.write(content)
    print('已核验：', name)
PY
```

脚本遇到不可读取对象即失败退出；不要把局部下载当成全部恢复。未挂入提交的对象没有永久可用保证。候选只是可选比对材料：若不可读，依据 main、恢复分支和第 4 节重做对应小修，不因此停工。主要实现源码已在恢复分支；任何旧聊天检查点或源码 ZIP 都不是接手的必需输入。
