# 小程序基础

## 当前行为

- 仓库根目录可被微信开发者工具识别为原生小程序项目，项目使用 AppID `wx958ebc33591b2bab`；
- 小程序打开首页后自动调用 `catledger-api.bootstrap`，失败时只显示可重试的公开状态，不在客户端保存服务端用户身份；
- `catledger-api` 只从微信云函数可信上下文取得 OpenID，将其摘要映射到内部用户，响应和日志不返回 OpenID、摘要或内部 uid；
- 首次初始化在一个事务中创建用户、身份映射和 16 个常用收入/支出分类，重复或并发调用复用同一套数据；
- 首版 MySQL schema 与迁移执行器已经进入代码，但尚未部署到云环境；账单上传、解析、交易和统计尚未实现。

## 数据流

“小程序启动 → 云函数可信微信身份 → SHA-256 身份摘要 → MySQL 身份映射 → 用户与默认分类事务初始化 → 返回分类列表”。客户端不能传入 uid 或 OpenID，数据库连接只读取云函数私有环境变量。

## 扩展点

- 常规业务进入 `cloudfunctions/catledger-api/`；
- 账单文件处理进入 `cloudfunctions/catledger-import/`；
- 公共请求/响应契约进入 `shared/`；
- MySQL 迁移进入 `migrations/`。

现有云环境包含其他项目资源。部署猫账时只新增 `catledger-api` 和 `catledger_*` 表；未确认数据库隔离与连接配置前不执行云端迁移。

## 版本规则

小程序上传版本使用语义化版本号。`catledger-api` 当前契约版本为 `v1`，函数实现版本为 `0.2.0`；数据库迁移按四位编号递增且已登记文件不可修改。开发版未经过微信审核和发布时，不视为正式可用版本。
