# 小程序基础

## 当前行为

- 仓库根目录可被微信开发者工具识别为原生小程序项目；
- 小程序展示猫账品牌和当前建设状态，不包含伪造的账本数据；
- `catledger-api` 提供最小启动入口，只从微信云函数可信上下文判断登录状态，不返回 OpenID；
- 正式 MySQL schema、账单上传、解析、交易和统计尚未实现。

## 数据流

当前只有“小程序启动 → 云开发初始化”的基础链路。业务数据链路从 MINI-1902 开始建立。

## 扩展点

- 常规业务进入 `cloudfunctions/catledger-api/`；
- 账单文件处理进入 `cloudfunctions/catledger-import/`；
- 公共请求/响应契约进入 `shared/`；
- MySQL 迁移进入 `migrations/`。

## 版本规则

小程序上传版本使用语义化版本号。解析器和数据库迁移各自维护显式版本；开发版未经过微信审核和发布时，不视为正式可用版本。
