# 贷款与分期

> 本页描述当前行为；代码冲突时以代码为准并修订本页。

## 当前能力

桌面工作台支持贷款和信用卡分期的测算、合同创建与修订、计划生成、正式交易候选、实际结算分配和安全撤销；移动端提供只读摘要。合同与计划位于 `personalfinance`，正式交易仍由核心账本持有。

## 会计语义

- 贷款到账：负债账户到资产账户的转账，不是收入；
- 偿还本金：资产账户到负债账户的转账，不是消费；
- 利息和费用：支出；
- 信用卡原消费转分期：不新增消费，只新增计划；
- 计划期次不等于实际还款，只有绑定正式交易后才推进进度。

## 合同与计划

合同保存计算参数和版本，计划保存预期日期、金额和剩余本金。来源信息不足时保持未知，不以零值伪造。算法变化不能静默改写历史合同结果。

## 账单发现

整理任务可以生成待确认分期候选。用户可关联已有合同、创建合同、标记不是分期或保留待完善。候选不会直接创建正式合同，也不应重复创建原消费。

## 当前产品位置

当前桌面主导航仍显示“贷款与分期”。已确认的目标需求要求它按需出现，并让分期候选退出普通账单阻塞流程；该信息架构调整尚未实现。

## 扩展边界

债务计划不得参与账户余额二次计算。新增还款方式、提前还款或不规则现金流时，必须版本化计算规则并补金标；正式结算继续通过现有交易关系和并发保护完成。
