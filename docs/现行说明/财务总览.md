# 财务总览

> 本页描述当前行为；代码冲突时以代码为准并修订本页。

## 它展示什么

登录后的主入口使用正式账户余额、正式交易和贷款计划关联生成个人财务总览。首屏只展示净资产、本月收入、本月支出、本月结余和下一笔待还；金额显隐同时覆盖卡片和趋势。账单覆盖、解析质量、重复记录及待处理诊断统一留在账单整理工作台，不在总览重复呈现。

桌面使用统一的上下文布局：顶部直接切换总览、交易明细、统计分析、账户和分类管理；业务导航最右侧只显示一个新增加号，菜单可选择“记一笔”或“导入账单”。“导入账单”进入包含上传、核对和账单记录的完整工作台，工作台使用全宽内容，左侧不再重复显示账单整理入口。交易明细使用全宽列表，标题旁展示当前范围的收支汇总，日期、类型和分页由内容区控制；交易日历和图片附件不再作为独立交易视图。分类管理只展示支出、收入、转账和分类层级，不继承记账工具、标签或用户设置侧栏。账户和贷款/分期共用账户模块入口，贷款工作台不再属于总览侧栏。统计只保留标准分析；自定义洞察、快捷模板、定时交易、标签、交易地点和地图均不再作为产品功能。模板与定时交易的前后端运行时已经移除，新数据库不再创建模板表；既有数据库中的旧表不会在预览阶段主动删除。标签管理与选择入口下线，但正式交易、导入、AI 和 MCP 仍复用既有标签 ID 契约，因此底层标签模型和接口继续保留。AI 剪贴板文本识别和图片识别继续作为可选记账入口；系统保留多个个人用户及其数据隔离，不提供机构或共享账本。

界面语言只注册简体中文与 English，首次使用默认简体中文、人民币、北京时间、公历和中文日期格式；其他上游翻译源码不进入前端构建。个人资料页直接展示语言和默认币种，日期、数字、财年、坐标和金额颜色等低频格式项收在“高级显示设置”中。该界面收敛不改变多币种、汇率、英文账单字段、文件编码和导入解析能力。

用户资料、偏好、安全、两步验证、应用锁和数据隐私使用同一个设置侧栏。桌面顶部不再常驻移动设备和主题按钮，它们收进头像菜单。汇率管理仅在账户中出现非默认币种时显示，直接路由和汇率引擎继续保留。移动端设置页不再混入账单整理、对账、贷款或重复总览入口：首页加号统一提供记一笔和导入账单，贷款与分期从账户页进入；旧移动页面和路由已移除。产品不提供“关于”入口或页面，MIT 与第三方许可继续保存在源码和发行材料中。

## 统计口径

- 净资产来自当前正式账户余额，不把贷款计划重复叠加为第二份负债；
- 生活消费来自正式支出交易，内部转账、余额调整、借款到账和偿还本金不计入；
- 未分类交易计入生活消费总额，但不进入餐饮、服饰等分类构成；
- 下一笔待还从已关联的贷款、分期和信用卡覆盖信息中选择最近到期事项；
- 今日、本周、本月、本年和 6/12/24 月趋势使用同一正式交易口径。

## 可信度

余额未核对、账单覆盖不完整、解析失败和待处理事项仍是账单整理与统计可信度的一部分，但不占据总览首屏。用户在账单整理工作台查看来源、解析与待处理问题。

## 下钻

总览数字可以进入账户、交易或贷款页面。正式交易可继续查看关联证据；高级覆盖表和技术信息从账单整理进入。

## 扩展边界

任何新汇总必须先定义正式交易、账户、关系或计划中的权威来源，不能在前端重新猜测会计口径。目标需求改变统计语义时先更新业务规则，再改服务与页面。
