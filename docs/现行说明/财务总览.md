# 财务总览

> 本页描述当前行为；代码冲突时以代码为准并修订本页。

## 它展示什么

登录后的主入口使用正式账户余额、正式交易、贷款计划关联和覆盖状态生成个人财务总览。首屏展示净资产、本月生活消费、下一笔待还和可信度；金额显隐同时覆盖卡片、图表和明细。

桌面使用统一的上下文布局：顶部直接切换总览、交易明细、统计分析、账户和分类管理；业务导航最右侧只显示一个新增加号，菜单可选择“记一笔”或“导入账单”。“导入账单”进入包含上传、核对和账单记录的完整工作台，工作台使用全宽内容，左侧不再重复显示账单整理入口。交易明细使用全宽列表，标题旁展示当前范围的收支汇总，日期、类型和分页由内容区控制；交易日历和图片附件不再作为独立交易视图。分类管理只展示支出、收入、转账和分类层级，不继承记账工具、标签或用户设置侧栏。账户和贷款/分期共用账户模块入口，贷款工作台不再属于总览侧栏。统计只保留标准分析；自定义洞察、快捷模板、定时交易、标签、交易地点和地图均不再作为产品功能。AI 剪贴板文本识别和图片识别继续作为可选记账入口；系统保留多个个人用户及其数据隔离，不提供机构或共享账本。

## 统计口径

- 净资产来自当前正式账户余额，不把贷款计划重复叠加为第二份负债；
- 生活消费来自正式支出交易，内部转账、余额调整、借款到账和偿还本金不计入；
- 未分类交易计入生活消费总额，但不进入餐饮、服饰等分类构成；
- 下一笔待还从已关联的贷款、分期和信用卡覆盖信息中选择最近到期事项；
- 今日、本周、本月、本年和 6/12/24 月趋势使用同一正式交易口径。

## 可信度

余额未核对、账单覆盖不完整、解析失败和待处理事项会降低可信度。当前实现会给出聚合提示并支持下钻，但目标需求中的事件级部分完成和更精确覆盖修订尚未实现。

## 下钻

总览数字可以进入账户、交易、贷款或账单整理页面。正式交易可继续查看关联证据。高级覆盖表和技术信息不放在首屏。

## 扩展边界

任何新汇总必须先定义正式交易、账户、关系或计划中的权威来源，不能在前端重新猜测会计口径。目标需求改变统计语义时先更新业务规则，再改服务与页面。
