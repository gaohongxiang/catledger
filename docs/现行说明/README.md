# 专题导航

主流程统一在[项目逻辑说明](../招财猫记账本入账逻辑说明.md)，这里只展开容易误解的子系统边界，不保存另一份任务状态。

| 专题 | 查什么 |
| --- | --- |
| [账单语义与工程验证](账单语义与工程验证.md) | 模板、原文、账户引用、语义冲突、来源身份、覆盖统计和规则版本 |
| [贷款管理](贷款管理.md) | 当前分期与旧普通贷款的区别，实际借还、计划、来源、连续进度、删除与重建 |
| [已入账账单维护](已入账账单维护.md) | 当前编辑/混选删除、退款补关联，以及保留后台更正/撤销的保护边界 |
| [客户端会话与读取](小程序基础.md) | 登录、分页缓存、写请求恢复、各类版本与状态所有权 |
| [界面视觉与导入状态](界面视觉与导入状态.md) | 现行导航、主题来源、输入/加载/错误/成功状态和原文展示 |
| [数据生命周期](数据生命周期.md) | 原件与结构化来源、个人导出、临时文件、快照和恢复验证边界 |

[账户与资金分配架构审查](账户与资金分配架构审查.md)是历史评审，不是另一份现行架构。当前账户及分配规则已归入逻辑主文档；原评审通过固定提交完整保留。

本目录文件沿用已有路径，避免把改名扩散成大量无关规格修改。修改规则时直接更新对应章节，不再在顶部追加日期段落覆盖下文。开发命令集中在[开发与验证](../开发与验证.md)。
