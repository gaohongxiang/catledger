# 贷款管理

当前 A1 支持独立列表、详情和资料编辑。入口为“我的”分类管理后的“贷款管理”；现有账本余额和收支仍来自 Account/Transaction。资料不会自动登记借款到账或余额调整。

本金基准表示基准日的日初已确认本金；金额未知时留空并显示待补充，明确零值与未知不同。同一账户多贷款按各自基准核对，不把本金明细重复加入净值。所有资料及游标受服务端可信微信身份隔离。

数据契约及状态见实施规划 19.5；接口 shared/catledger-api.json；新增迁移 0013_loan_metadata.sql。页面保存使用 pending-ledger-write 的原请求核实/重试，详情成功后单独回读；网络错误保留表单，不以缓存余额判成功。

本阶段源码入口：catledger-api/src/loan-service.js、loan-domain.js；miniprogram/pages/loans、loan-detail。行为验证：test/loans.test.js、test/ui-all-pages.test.js。实际借还及还款计划未在 A1 中完成；后续 A2/B 将在此更新实际行为。
