# 全页面视觉与显示状态

当前界面交付分支：`codex/mini-1906ui-all-pages`。覆盖 `app.json` 注册的 11 页、底栏、登录、详情、编辑、筛选、核对和分类弹层；不是旧 Web 分支。

## 视觉
- 全局排版保留系统字体，正文 28rpx/400、标题 36rpx/500，数字自然字距。不增加字体下载与运行时依赖。
- 暖橘的普通次级表面为中性暖灰，选中提示才使用浅橘；其余五主题配色和财务含义不变。首页净值卡保留已确认的局部渐变。
- 创建账户恢复「新建账户｜名称｜类型」同行；左段局部陶橘白字。信用类型短标签不改原生选项或保存值。
- 页头主操作（新建账户/新建分类/新增贷款）统一为全局 `.head-cta` 实色胶囊按钮：主题橘底、白字白图标、小字紧凑；各页不再自造纯文本或描边按钮。

## 显示行为
- 首页沿用 `hasDashboard`；明细、账户、分类沿用 `hasLoaded`。账本、个人页和统计新增只描述成功读取的 `hasLoaded`，初次读取未成功显示 `—`，不把占位零值当真实余额。刷新失败保留已有结果并显示错误。
- 明细、统计切换月份时使原查询的展示失效；读取中拒绝切换月份或筛选，避免新月份显示旧结果。接口、金额和请求结构不变。
- 记账编辑新增 `preparing/formReady` 只控制表单准备和重试显示；保存逻辑、账户与退款约束仍由原处理器执行。
- 导入继承 PR8 的紧凑账户布局；记录摘要已改为页面内常驻公式，原 `record-summary` 组件及注册已移除。合并 PR7 的付款校验说明、来源展开和“移除最后一个待解析文件后继续成功文件”的显示条件，不新增重复摘要状态。
- 付款提示来自原模型 `valid/reason`；提示字符串不得决定保存权限。`issueSourceExpanded` 仅本地展开，不写整理决定。
- 统计柱高与分类比例直接按已有比例投影，零比例为零高度；点击月份/日期显示已有格式化金额，不重算财务数据。
- 分类列表 116rpx 固定行高与拖动命中计算一致；长名称列表省略，完整名称在详情与编辑中保留。
- 账户/分类/统计弹层内的错误不会藏在遮罩背后。忙碌禁用、原生选择器、原字段与事件绑定保留。
