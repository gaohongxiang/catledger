# 界面视觉与导入状态（精修候选）

范围：MINI-1906UI-R1。现状基线为 main@1b37788c；本说明随精修分支交付，不表示已合并、已部署或已完成原生验收。任务状态仅维护在实施规划。

## 视觉和扩展边界

首页与导入页采用普通无衬线字体、常规正文/中等标题、自然字距和轻卡片。暖橘覆盖只在页面 `.theme-warm-ledger` 内定义局部变量，其余主题继续使用已有 registry；不加载远程字体、不新增依赖。首页金额保留原字符串，超长摘要改纵向，不省略负号或小数。首页样板底栏仅在选中首页时启用，不改变导航。

## 数据流

来源与关系 → 原工作台模型 → WXML 展示，方向未变。文件操作读 `phase/uploadSummary`；账户确认数量读 `confirmed`；核对/分类读各自状态数组；付款金额及可保存状态由原模型生成。新增 record-summary 组件只维护本地 expanded，四项计数始终可见。原始证据、失败重试、历史忽略与所有提交门禁保留。

## 状态与检查

未选文件只显示选择；有队列才显示解析；解析中原位反馈且禁用重复操作；完成后只突出下一步。账户建议不等于确认。新建账户恢复“处理方式｜名称｜类型”的同一行控件，右侧白底、细分隔线，暖橘左侧使用低饱和陶橘与白字；其他主题沿用本身强调色。长名称仍可编辑，类型使用紧凑标签，原生选择器保留完整选项，放大字号时可在本格内换行。付款全部分配的语义不变，必填说明和金额不平仍阻止保存。详细分支与原处理器入口见《入账逻辑说明》0.2.2。
