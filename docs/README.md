## 只有三个阅读层次

```text
第一层：项目逻辑说明 —— 连贯理解现有系统
第二层：规则 / 架构 / 专题 / 开发 —— 按问题查细节
第三层：归档 / specs / Git 提交 —— 追溯历史，不充当现行手册
```

“代码存在”“已经部署”“真机验收完成”必须分开写。当前实现看逻辑和代码，任务状态只在实施规划维护；需求不复制发布记录，架构不混入尚未落地的未来服务。
