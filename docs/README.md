# 招财猫记账本文档

> 英文及技术代号为 `CatLedger`；中文正式产品名为“招财猫记账本”。

## 项目概览

招财猫记账本是以批量账单导入为主、手工记账为辅的微信原生小程序。系统先把支付宝、微信和银行等来源资料整理成可追溯的正式账本，再基于正式交易计算余额、收支和净值；不替用户执行付款、转账、投资或借款。

```text
来源文件 → 原始证据 → FinanceUpdate → EconomicEvent / ReviewIssue
        → 用户确认 → Transaction / Account → 余额、收支和统计
```

只有正式交易影响余额和统计。多份资料可以是同一次现实资金活动的不同证据，不能因此重复入账；金额、时间或文本接近也不能单独触发自动合并。

当前任务、依赖、部署和验收状态统一查阅 [实施规划](./招财猫记账本实施规划.md)。本索引不再重复维护一份当前推进队列、发布版本或测试总数。源码实际行为以代码、迁移和测试证据核对；规划不代表已经实现或发布。

## 文档职责与历史资料

入账逻辑说明用于理解流程；用户需求和业务规则定义产品行为与判断标准；架构描述边界；实施规划维护唯一当前状态；specs 保存任务契约、验收与证据指针；现行说明描述已实现行为。出现冲突时核对代码、迁移和验证记录，修订不准确的说明，不能把历史数字改写成新验证。

原 `specs/mini-1906a-ledger-integrity/` 是已拆分总体设计的历史来源，不作为整包直接实施。其他历史任务的执行顺序以实施规划当前记录为准。不可变分录、影子双写等长期设计不因保留文档就成为 MINI-1915 一期前置。

具体账单模板由解析代码、合成或脱敏测试夹具和现行说明共同维护，不在多个入口复制易漂移的字段表。旧 Web 版及其构建资料保存在 `catledger-web` 分支和 `web-v2-final` 标签中；本索引面向小程序主线。
