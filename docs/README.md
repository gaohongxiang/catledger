# 个人财务文档导航

本目录按“产品需求、业务规则、目标设计、当前行为、实施状态、运维、未来规划、历史归档”分层。不同层回答不同问题，不互相复制正文。

## 新会话怎么读

普通开发会话只按任务读取必要内容：

1. 先读根目录 `AGENTS.md`；
2. 再读[个人财务实施规划.md](./个人财务实施规划.md)的 0.1～0.6 节和第 19 章；
3. 涉及产品行为时读[个人财务用户需求.md](./个人财务用户需求.md)相关章节；
4. 涉及会计对错时读[个人财务业务规则与验收.md](./个人财务业务规则与验收.md)相关章节；
5. 涉及当前代码行为时读 `现行说明/` 对应页面；
6. 涉及 DESIGN-1701、待处理问题、同一事件、退款或服务端可入账校验时，读[个人财务待处理问题与关系裁决设计.md](./个人财务待处理问题与关系裁决设计.md)；
7. 涉及来源身份、重复文件、解析重放、相同内容交易或跨来源基数时，读[个人财务来源记录身份与重复语义设计.md](./个人财务来源记录身份与重复语义设计.md)；
8. 只有追溯旧契约、提交或发布证据时才进入 `归档/`。

不得为普通任务从头阅读归档或完整历史规划。

## 文档变更路由

- 用户可感知行为变化：先改需求，再改业务规则；
- 对错标准变化但界面不变：改业务规则；
- 公共接口、数据表或状态机变化：先在实施规划登记设计任务并冻结设计；
- 设计仍待用户确认时：使用独立候选设计文档，明确当前行为、非目标、迁移边界和待确认结论，不把候选写成已实现事实；
- 仅新增解析模板：改代码和账单上传现行说明；
- 当前行为变化：同一集成更新对应现行说明；
- 阶段完成：详细证据进入归档，实施规划只留提交、结论和指针。
