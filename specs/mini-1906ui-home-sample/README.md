# MINI-1906UI-HOME：首页视觉样板

状态：待验收。首页样板已纳入本轮导入界面精修分支；统一范围和验证见 `../mini-1906ui-import-refinement/README.md`，未集成 main。

基线：`1b37788ced1b3ca4cdf4f8a9275bc94db2ec6f62`。视觉方向采用用户选定的第一版：清秀字感、暖白表面、轻卡片和克制的暖橘；不是第二版展示海报。

## 本批边界

只调整 `pages/index` 的 WXML/WXSS，以及首页选中时的底栏样式。保留页面控制器、登录、刷新、金额格式化、图表比例、最近三条账目、账户方向和所有跳转事件。保留六个主题及全局 theme registry，不向其他页面推广尚未确认的首页样板。

不修改云函数、公共接口、数据库迁移、账单解析、账户身份、退款、资金分配或入账门禁。不增加前端依赖和字体下载。浏览器预览中的数据、图标占位与头像裁片不进入小程序生产代码。

## 展示规则

- 中文标题使用中等字重及自然字距，正文常规字重；首页金额改为系统无衬线字体、等宽数字，不强制 DIN 窄体。
- 暖橘渐变只定义在 `.home-page.theme-warm-ledger` 的局部变量中。其他主题继续读取既有 token，不被硬编码为橘色。
- 净值始终绑定 `netWorthText`，不改成总资产，不修改负号、币种、小数或单位。
- 月度摘要为三个轻卡片。当任一金额字符串超过 12 个字符时，只将卡片改为纵向布局；仍直接展示原字符串，不截断或缩写金额。
- 账户和最近账目使用白色列表容器，长名称可换行，保留“余额/待还”、来源与时间。
- 刷新失败保留“重试”；未登录、无云开发能力、无数据和首次加载的条件保持原样。
- 底栏仅在 `selected === 0` 时启用样板 class。其他 tab、记账弹层、隐藏逻辑与点击 handler 不变。
