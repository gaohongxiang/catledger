# MINI-1906V 实施计划

- [ ] 0. 冻结实际环境基线

  - 记录两支函数版本、运行时、状态、VPC、环境变量键和触发器
  - 记录 AppID 与体验版版本
  - 对比实施规划，发现漂移即停止

- [ ] 1. 验收身份、隔离与私有上传
  - 按需登录和重复 bootstrap
  - 服务端可信身份与身份形状字段拒绝

  - 随机对象路径与精确对象校验
  - _Requirement: V2, V7_

- [ ] 2. 验收单文件、多文件与恢复
  - 支付宝 App/Web CSV 和微信 CSV/XLSX
  - 混合多文件独立上传与解析
  - 单文件失败隔离、重试和移除
  - 上传中断、返回工作台和同幂等键恢复
  - 未入账重复文件复用与已入账来源阻断
  - _Requirement: V3, V5_

- [ ] 3. 验收账户与经济语义
  - 已有账户、新建账户、仅本次不计入和以后默认不计入
  - 本人转账 from/to 独立确认
  - 自动、人工和待关联退款
  - 花呗/信用购原子账户与聚合还款守恒
  - 分类门槛、补分类与结构化排除原因
  - _Requirement: V4, V5_

- [ ] 4. 验收整批入账、回滚和幂等
  - 阻塞问题清零后成功整批入账
  - 版本冲突、现金负数、身份冲突和事务失败
  - 失败后账户、映射、交易、余额和统计零变化
  - 相同请求重放与相同键不同摘要冲突
  - _Requirement: V6_

- [ ] 5. 验收入账后统一刷新
  - 账户余额和明细
  - 月度收支、近半年趋势、每日统计和分类排行
  - 未分类补全与退款统计
  - 导入记录和原始证据下钻
  - _Requirement: V6_

- [ ] 6. 核对隐私与对象生命周期
  - 日志、截图和记录不含敏感值
  - 成功、放弃和重复裁决后的对象清理
  - 清理失败只进入可重试状态

  - _Requirement: V7_

- [ ] 7. 收口验收结果
  - 为每个场景记录脱敏结果
  - 缺陷拆成独立任务或标记阻塞
  - 同步实施规划、现行说明和回归基线
  - 全部通过后同时完成 MINI-1905/1906 与 MINI-1906V
  - 下一任务登记为 MINI-1906A1
  - _Requirement: V1-V7_

## 执行门禁

1. 未记录实际平台基线不得开始业务验收。
2. 不使用真实微信身份不得把完整链路写成通过。
3. 任一 posting 故障后存在正式数据残留即阻止完成。
4. 任一敏感内容进入日志、截图或仓库即停止并先清理。
5. 发现代码缺陷只记录和拆任务，不在本验收任务中扩大实现范围。
6. 未取得单独授权不得部署新代码、上传新体验版、提交审核或正式发布。
