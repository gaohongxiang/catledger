需求：新增贷款统一为分期，不再选择普通借款/消费分期。名称、分类、原借款金额、总期数、四种还款方式、还款额/利率、首次还款日、历史已还期数、优惠与费用沿用参考页面；额外选择本账本有效负债账户。历史借款兼容读取维护，不改写旧数据。

历史口径：已还期数是接入前已确认的连续历史进度，不按日期自动已还，不生成历史交易。原始本金与接入时本金基准分开；试算后由用户确认剩余本金和开始核对日期。保存新分期在同一事务中登记资料与剩余期次，不产生资金流水或重复计入负债。以后进度以实际还款及期次关联更新。

界面设计：
1. 目的：根据合同或账单一次录入分期并得到可核对的后续计划；关联账户负责映射本账本，不从账户总负债反推单笔本金。

3. 色彩与字体：米白 #FAF8F4、正文 #2C2823、强调 #BE5B24、辅助 #79716A；PingFang SC 正文、现有 serif-title 标题和 money-number 金额。
4. 布局：名称与分类 → 关联负债账户 → 原金额/期数 → 还款方式/测算依据 → 首期日/历史期数 → 可收起的优惠与费用 → 剩余本金及计划核对 → 保存。
