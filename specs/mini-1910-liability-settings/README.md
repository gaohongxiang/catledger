## 契约

- `statementDay` / `repaymentDay` 为 null 或 1..31 的整数，互相独立，允许跨月。只保存每月约定日，不推算本期账单、节假日顺延或实际到期日，也不改贷款计划。
- `creditLimitMinor` 为 null 或非负整数分字符串，上限沿用金额边界；null 是未设置，明确 0 是零额度。额度不作为余额、欠款或统计输入。
- `0023_account_billing_settings.sql` 连续、可重入新增三列与约束；既有账户默认 null。资产账户不接受非空设置。
- `accounts.create/createBatch` 支持可选字段；`accounts.update` 改为部分更新，省略保留，null 清空，保持可信身份、活动账户、版本和幂等事务；只改名不擦除设置。
- `accounts.list` 返回完整设置与 `liabilitySettingsVersion=1`；旧服务无版本标记时客户端禁止提交非空设置，避免字段被静默忽略。
- 私有数据导出清单包含新增三列，导出 schemaVersion 升为 22；历史 null 值保持 null，恢复时不丢账单资料。
- 负债详情不显示校正入口；资产保留原流程。原有期初调整及历史记录不删除，账面仍由正式交易聚合。

## 界面规格

账户明细子页面路径为 `pages/account-transactions/index`；复用通用明细数据和展示，返回只执行一次 `navigateBack`。

目的：在创建及账户详情直接维护账单信息。沿用暖橘手账的编辑式风格，现有六主题令牌（#FAF8F4、#2C2823、#BE5B24、#746A60）、PingFang SC 正文与现有宋体标题。余额／待还摘要卡片内嵌「查看明细」入口，沿用当前账户筛选跳到明细；账户详情将账户明细作为子页面打开，明细页顶部入口直接返回上一页账户详情，详情页再返回账户列表；调整明细筛选不改变上一页，换会话后清除旧账户筛选和返程入口。账单资料左标签右数值，设置弹层复用原生日期选择及金额输入。账单日/还款日有「未设置」选项，额度留空清除；创建时仅负债类型出现。延续项目现有布局和字体，不另引入设计系统。
