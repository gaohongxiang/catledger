# MINI-1904B 设计：暖橘编辑式轻账本

## 1. 分层

1. `miniprogram/app.wxss` 定义不随主题变化的基础令牌：字阶、间距、触控尺寸、图标尺寸、安全区和动效。
2. `miniprogram/theme/registry.js` 保存主题语义色和受控外观令牌，不控制页面间距、字阶或触控盒。
3. 共享界面组件承担章节标题、状态提示、底部面板和登录面板的一致结构；业务页只组合数据与组件。
4. 页面 WXSS 只保留本页独有布局，不重复全局字阶、按钮、分区或空状态。

## 2. 令牌契约

- 基础尺寸：页边距 `32rpx`，最小触控高度 `88rpx`，字阶 `24/28/32/40/56rpx`，间距遵循 `8rpx` 倍数。
- 圆角：基础语义为 `12/18/24rpx`，主题外观只能在受控范围内投影。
- 阴影：普通内容默认无阴影；仅浮动加号和模态面板使用抬升阴影。
- 图标：继续使用已引入的 Lucide SVG 系列，同一层级保持轮廓风格和线宽，不使用 Emoji。
- 动效：仅用 WXSS 颜色、透明度和位移反馈，时长 `120/180/240ms`，不引入 GSAP 或 Web 动画方案。

## 3. 主题结构

`registry.js` 保留现有六个 ID 和本机存储兼容性。令牌区分为：

- 语义调色：`page/surface/ink/textMuted/accent/income/expense/danger/line`。
- 受控外观：`border/shadowSoft/shadowLifted/radiusLarge/radiusMedium/radiusSmall`。
- 固定基础：间距、字体、字号、触控区、页面宽度、底栏高度。

移除默认暖橘主题中偏黄的大面积渐变语义，净值区使用稳定暖橘底和墨色数字。

## 4. 页面方案

- 首页：压缩净值区高度；本月三项摘要紧贴净值；趋势、账户和最近账目使用统一章节标题与线性列表。
- 明细：月份/日期、三项摘要和筛选形成紧凑顶部工具区；账目金额右对齐，备注与账户作为次级信息。
- 账本：保留三个数量摘要和两个同规格管理行，不就地铺开分类。
- 我的：用户身份行与数量摘要合并为轻量页头；菜单只保留主题、数据与隐私、关于和退出。
- 底栏：四个页签图标与文字保持一致基线；中央加号仅显示加号，不显示标题。

## 5. 可用性与验证

- 使用原生 `button`、`picker`和有明确 `role/aria-label` 的点击行；视觉图标可小于点击盒，点击盒不小于 `88rpx`。
- 收入/支出除颜色外同时有文字标签；错误与禁用状态不仅依赖透明度。
- 检查小屏、常规屏、安全区、长昵称、长账户名、空数据、加载、错误、登录/未登录和六套主题。
- 自动化覆盖主题令牌完整性、导航信息架构、底栏安全区、受保护页登录门禁和“我的”菜单边界。
